# Risk V1 Dashboard

Public research dashboard for the canonical Risk V1 strategy family.

- Source of truth: private `galbbb2772/risk-v1-lab`
- Dashboard publishes derived research/performance data only.
- No credentials, private source code, or secrets are mirrored here.
- Historical and Forward OOS are kept strictly separate.

## Dashboard contents

- Historical Strict Next-Open NAV and drawdown
- Risk V1 + 3M Treasury cash-management overlay
- Annual and monthly benchmark comparisons
- 308-trade research ledger view
- Forward OOS status, account slots, NAV and trades
- Frozen strategy rules

GitHub Pages deployment is defined in `.github/workflows/pages.yml`.
